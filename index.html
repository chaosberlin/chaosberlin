04 / README/help
Small surface.
Clear rules.
01   Request a name
Fork chaosberlin/chaosberlin, add requests/<name>.yaml, and open a PR. The claim channel can generate the file for you.
02   Point it somewhere
Use CNAME for a hostname, A for IPv4, or AAAA for IPv6. Configure the custom domain at your hosting provider as well.
03   Review before provisioning
Validation checks the request. A maintainer reviews it. Merging triggers DNS provisioning when the deployment credentials are configured.
04   Keep infrastructure names free
Names such as www, mail, api, and admin are reserved. Only the owner (or a listed collaborator) can change a name, and only the owner can delete it.
05   Mail is private
The public repo contains namespace requests. Passwords, messages, and mailbox credentials never belong there. Real mailboxes are planned; the mailbox channel is a design preview.
